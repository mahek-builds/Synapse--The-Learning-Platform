Design a premium, modern, dark-theme SaaS web application called Synapse AI.

The platform is an AI-powered learning and assessment system built using Agentic AI. It helps users learn concepts, generate quizzes, take assessments, perform research, and track progress through multiple AI agents.

The design should feel like a combination of ChatGPT, Linear, Notion, Perplexity, and Vercel.
